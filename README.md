# Shelf

A small Mac app that gives you a shelf to set files down while you move them. Pick up files, shake your mouse, and the shelf appears.

**Download:** [Shelf.zip](https://github.com/tamilust-create/shelf-releases/releases/latest/download/Shelf.zip). Needs macOS 15 or newer.

## Install

1. Unzip it and drag `Shelf.app` into your Applications folder.
2. The first time, macOS says it "could not verify" Shelf. Shelf is not sold through Apple, so allow it once:
   - Terminal: `xattr -dr com.apple.quarantine /Applications/Shelf.app`, then open Shelf, or
   - System Settings, Privacy & Security, scroll down and click **Open Anyway**.
3. Shelf lives in the menu bar. Choose **About Shelf / How to Use…** for a short guide.

Shelf checks for updates itself and always asks before installing one.
